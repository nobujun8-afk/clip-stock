# クリップストック ⚽

X で見つけた練習メニューや戦術の動画を、分類・タグ・メモ付きで保存して後から見返すための Web アプリ（PWA）です。
iPhone と PC で同期でき、すべて無料枠で動きます。

- 保存するのは投稿のリンクだけです。再生は X の公式埋め込みを使うので、動画ファイルはダウンロードしません。
- 分類（練習メニュー・戦術・個人技術・身体操作・その他）、タグ、メモ、視聴済みの管理、検索ができます。
- `firebase-config.js` が空のままだと「この端末のみ」モードで動きます（同期はされません）。

## 1. 公開する（GitHub Pages・無料）

1. GitHub のリポジトリで **Settings → Pages** を開く
2. Source を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存
3. 数分後、`https://nobujun8-afk.github.io/clip-stock/` で開けるようになる

※ 無料プランで GitHub Pages を使うには、リポジトリを公開（Public）にする必要があります。
保存したクリップはリポジトリではなく Firebase に入るので、リポジトリを公開しても中身は他人に見えません。

## 2. 同期を有効にする（Firebase・無料の Spark プラン）

1. https://console.firebase.google.com で「プロジェクトを追加」（Google アナリティクスはオフで OK）
2. **Authentication → ログイン方法** で「Google」を有効にする
3. **Authentication → 設定 → 承認済みドメイン** に `nobujun8-afk.github.io` を追加する
4. **Firestore Database → データベースを作成**（本番モード、ロケーションは `asia-northeast1` など）
5. Firestore の **ルール** タブに、このフォルダの `firestore.rules` の中身を貼り付けて公開する
6. **プロジェクトの設定 → マイアプリ → ウェブ（</>）** でアプリを登録し、表示された `apiKey` / `authDomain` / `projectId` / `appId` を `firebase-config.js` に貼り付けてコミットする

`apiKey` は公開しても問題ない値です。データは上のルールで、ログインした本人しか読み書きできません。

## 3. iPhone で使う

1. Chrome（または Safari）で公開 URL を開き、共有ボタン（↑）→ **ホーム画面に追加**
   - ショートカットは iPhone の「既定のブラウザ」で開きます。Chrome を使う場合は **設定 → アプリ → デフォルトのブラウザ** を Chrome にしてください
   - ログインはブラウザごとに 1 回必要です
2. 右上の「Googleでログイン」でログインする（PC でも同じアカウントでログインすれば同期されます）

### X の共有ボタンからワンタップで保存する（ショートカット）

「ショートカット」アプリで、次の手順で 1 つ作ります。

1. 新規ショートカットを作り、詳細設定で **「共有シートに表示」をオン**、受け取る種類を「URL」と「テキスト」にする
2. アクション **「URLをエンコード」**（入力：ショートカットの入力）を追加
3. アクション **「テキスト」** に `https://nobujun8-afk.github.io/clip-stock/?url=` と入力し、その末尾に 2 の「エンコードされたURL」を差し込む
4. アクション **「URLを開く」**（入力：3 のテキスト）を追加
5. 名前を「クリップに保存」にする

これで、X の投稿の **共有 → クリップに保存** をタップすると、URL が入った状態でアプリが開きます。分類を選んで「保存」を押せば完了です。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体 |
| `firebase-config.js` | Firebase の接続設定（同期を使うときに記入） |
| `firestore.rules` | Firestore のアクセスルール |
| `manifest.webmanifest`, `icon.svg` | ホーム画面に追加したときの設定 |
